--- erklaerung
Jetzt wird aus deinen Klassen eine **echte Anwendung**: Ein Menü fragt, was der Benutzer tun möchte, liest die Eingaben und ruft deine `Bank`-Methoden auf.

## So funktioniert die Eingabe hier
Starte das Programm mit **Strg+Enter**. Das Menü erscheint und das Programm **wartet**. Tippe deine Auswahl in das **Eingabefeld unter der Ausgabe** und drücke **Enter**. Mit `0` beendest du das Programm, mit **■ Stopp** jederzeit.

## Was schon fertig ist
- Das **Menü** mit einer `while`-Schleife und einem `switch`
- Ein **Demo-Konto** (DE-0001, Anna Schmidt, 1.000 €), damit du sofort testen kannst
- Fehler (`IllegalArgumentException`, `IllegalStateException`) werden im Menü abgefangen und als `Fehler: ...` angezeigt. Deine Bank-Klassen werfen sie ja schon!

## Hilfsmethoden zum Einlesen
Diese Methoden fragen bei Tippfehlern nach:
- `frage("Text: ")` liest eine Zeile Text.
- `frageBetrag("Betrag: ")` liest eine Zahl. `49,99` und `49.99` gehen beide.
- `frageDatum("Geburtsdatum: ")` liest ein Datum im Format `TT.MM.JJJJ`.

## Beispiel: so sieht eine fertige Aktion aus
```java
static void kontoauszug() {
    String nummer = frage("Kontonummer: ");
    bank.finde(nummer).kontoauszug();
}
```

| Baustein | Was er bedeutet |
|---|---|
| `static void kontoauszug()` | Eine Methode für einen Menüpunkt. Sie gibt nichts zurück. |
| `frage("Kontonummer: ")` | Zeigt den Text an und liefert die Eingabe als String. |
| `bank.finde(nummer)` | Sucht das Konto und liefert ein `Konto`-Objekt. |
| `.kontoauszug()` | Wird direkt auf dem gefundenen Konto aufgerufen. Zwei Aufrufe hintereinander mit Punkt nennt man **Verkettung**. |

## Bonus-Ideen für coole Features
Wenn alles läuft, erweitere deine App – such dir aus, was dich reizt:
- **Statistik** (neuer Menüpunkt 7): Anzahl Konten, Gesamteinlagen, Kunde mit dem höchsten Guthaben (Tipp: `stream().max(Comparator.comparingDouble(Konto::getKontostand))`).
- **Kundendaten prüfen**: Im record `Kunde` einen kompakten Konstruktor schreiben, der leere Namen und E-Mails ohne `@` ablehnt: `Kunde { if (!email.contains("@")) throw new IllegalArgumentException("Ungültige E-Mail"); }`
- **PIN-Schutz**: Jedes Konto bekommt eine 4-stellige PIN, die vor dem Auszahlen abgefragt wird.
- **Girokonto mit Dispo & Sparkonto mit Zinsen**: `Konto` wird abstrakt, zwei Unterklassen überschreiben `auszahlen` – perfekt, um **Vererbung und Polymorphie** im Interview zu erklären.
- **Konto schließen**: nur erlaubt, wenn der Kontostand 0 ist.
- **Kunde suchen**: alle Konten zu einem Nachnamen anzeigen (Stream mit `filter`).
- **BigDecimal** statt `double` für exakte Geldbeträge.

record Kunde(String vorname, String nachname, String email, LocalDate geburtsdatum) {
    String name() {
        return vorname + " " + nachname;
    }

    int alter() {
        return Period.between(geburtsdatum, LocalDate.now()).getYears();
    }
}

record Transaktion(String text, double betrag) {}

class Konto {
    private final String kontonummer;
    private final Kunde inhaber;
    private double kontostand;
    private final List<Transaktion> verlauf = new ArrayList<>();

    Konto(String kontonummer, Kunde inhaber) {
        this.kontonummer = kontonummer;
        this.inhaber = inhaber;
    }

    void einzahlen(double betrag) {
        einzahlen(betrag, "Einzahlung");
    }

    void einzahlen(double betrag, String text) {
        if (betrag <= 0) throw new IllegalArgumentException("Betrag muss positiv sein");
        kontostand += betrag;
        verlauf.add(new Transaktion(text, betrag));
    }

    void auszahlen(double betrag) {
        auszahlen(betrag, "Auszahlung");
    }

    void auszahlen(double betrag, String text) {
        if (betrag <= 0) throw new IllegalArgumentException("Betrag muss positiv sein");
        if (betrag > kontostand) throw new IllegalStateException("Nicht genug Guthaben");
        kontostand -= betrag;
        verlauf.add(new Transaktion(text, -betrag));
    }

    void kontoauszug() {
        System.out.println("--- Kontoauszug " + kontonummer + " (" + inhaber.name() + ") ---");
        for (Transaktion t : verlauf) {
            System.out.println(String.format("%12s  %s", euro(t.betrag()), t.text()));
        }
        double eingaenge = verlauf.stream().filter(t -> t.betrag() > 0).mapToDouble(Transaktion::betrag).sum();
        double ausgaenge = verlauf.stream().filter(t -> t.betrag() < 0).mapToDouble(t -> -t.betrag()).sum();
        System.out.println("Eingänge: " + euro(eingaenge) + " | Ausgänge: " + euro(ausgaenge));
        System.out.println("Kontostand: " + euro(kontostand));
    }

    String getKontonummer() { return kontonummer; }
    Kunde getInhaber() { return inhaber; }
    double getKontostand() { return kontostand; }

    static String euro(double betrag) {
        return String.format("%,.2f €", betrag);
    }

    @Override
    public String toString() {
        return "Konto " + kontonummer + " | " + inhaber.name() + " | " + euro(kontostand);
    }
}

class Bank {
    private final String name;
    private final Map<String, Konto> konten = new LinkedHashMap<>();
    private int naechsteNummer = 1;

    Bank(String name) {
        this.name = name;
    }

    Konto kontoEroeffnen(Kunde kunde) {
        if (kunde.alter() < 18) throw new IllegalArgumentException("Kunde muss mindestens 18 Jahre alt sein");
        String nummer = String.format("DE-%04d", naechsteNummer++);
        Konto konto = new Konto(nummer, kunde);
        konten.put(nummer, konto);
        System.out.println("Neues Konto " + nummer + " für " + kunde.name());
        return konto;
    }

    Konto finde(String kontonummer) {
        Konto konto = konten.get(kontonummer);
        if (konto == null) throw new IllegalArgumentException("Konto nicht gefunden: " + kontonummer);
        return konto;
    }

    void ueberweisen(String von, String nach, double betrag) {
        Konto quelle = finde(von);
        Konto ziel = finde(nach);
        quelle.auszahlen(betrag, "Überweisung an " + nach);
        ziel.einzahlen(betrag, "Überweisung von " + von);
    }

    void uebersicht() {
        System.out.println("=== " + name + " ===");
        double summe = 0;
        for (Konto k : konten.values()) {
            System.out.println(k);
            summe += k.getKontostand();
        }
        System.out.println("Summe aller Einlagen: " + Konto.euro(summe));
    }
}
