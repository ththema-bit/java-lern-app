## Kunde als record
Ein Kunde besteht nur aus Daten, die sich nicht ändern – perfekt für einen `record`. Records dürfen auch eigene Methoden haben:

```java
record Kunde(String vorname, String nachname, String email, LocalDate geburtsdatum) {
    String meineMethode() {
        return "Hallo " + vorname;   // auf die Felder greifst du direkt zu
    }
}
```
| Baustein | Was er bedeutet |
|---|---|
| `record Kunde` | Ein record namens `Kunde`: eine Datenklasse, deren Werte sich nach dem Erzeugen nicht ändern. |
| `( ... )` | Die **Felder**, wie Parameter geschrieben: Typ und Name, durch Komma getrennt. Java erzeugt daraus Konstruktor, Getter, `equals`, `hashCode` und `toString`. |
| `LocalDate geburtsdatum` | `LocalDate` ist Javas Typ für ein Datum ohne Uhrzeit. |
| `{ ... }` | Optional: eigene Methoden. Ist er leer, schreibt man `{}`. |
| `new Kunde("Anna", "Schmidt", "a@mail.de", LocalDate.of(1990, 5, 1))` | So erzeugst du einen Kunden: Die Werte kommen in derselben Reihenfolge wie die Felder. |

Von außen liest man die Felder über gleichnamige Methoden: `kunde.vorname()`, `kunde.email()`.

## Konto – Kapselung in der Praxis
Der `kontostand` ist `private` und es gibt **keinen Setter**! Geld kommt nur über `einzahlen` und `auszahlen` aufs bzw. vom Konto. So kann niemand den Kontostand "einfach so" verändern.

## Ungültige Eingaben mit Exceptions ablehnen
- `IllegalArgumentException` – das **Argument** ist ungültig (z. B. negativer Betrag)
- `IllegalStateException` – das Objekt ist im **falschen Zustand** für diese Aktion (z. B. nicht genug Guthaben)

```java
if (alter < 0) {
    throw new IllegalArgumentException("Alter darf nicht negativ sein");
}
```

> **Hinweis:** Wir benutzen hier `double`, damit es einfach bleibt. Echte Banksoftware nimmt `BigDecimal`, weil `double` Rundungsfehler hat – das kannst du im Interview erwähnen!

## Konten in einer Map speichern
Konten sucht man über ihre Nummer – dafür ist eine `Map<String, Konto>` ideal (Kontonummer → Konto). Mit einer `LinkedHashMap` bleibt die Reihenfolge der Eröffnung erhalten.

```java
Map<String, Konto> konten = new LinkedHashMap<>();
konten.put("DE-0001", konto);
Konto k = konten.get("DE-0001");   // null, wenn es die Nummer nicht gibt
```

## Fortlaufende Nummern
```run
int naechsteNummer = 1;
for (int i = 0; i < 3; i++) {
    String nummer = String.format("DE-%04d", naechsteNummer++);   // %04d = 4 Stellen, vorne Nullen
    System.out.println(nummer);
}
```

| Baustein | Was er bedeutet |
|---|---|
| `String.format(...)` | Baut einen Text nach einer Vorlage, gibt ihn aber nicht aus. |
| `"DE-%04d"` | `DE-` steht fest im Text. `%d` ist der Platzhalter für eine Ganzzahl, `4` heißt „mindestens 4 Stellen breit“, die `0` davor „mit Nullen auffüllen“. Aus 7 wird `DE-0007`. |
| `naechsteNummer++` | Liefert den **aktuellen** Wert für den Platzhalter und erhöht die Variable **danach** um 1. So bekommt jedes Konto eine neue Nummer. |

## Alter berechnen mit LocalDate
```run
java.time.LocalDate geburt = java.time.LocalDate.of(1995, 4, 12);
int alter = java.time.Period.between(geburt, java.time.LocalDate.now()).getYears();
System.out.println("Alter: " + alter);
```
| Baustein | Was er bedeutet |
|---|---|
| `LocalDate.of(1995, 4, 12)` | Erzeugt ein Datum: Jahr, Monat, Tag. |
| `LocalDate.now()` | Das heutige Datum. |
| `Period.between(a, b)` | Der Zeitraum zwischen zwei Daten, in Jahren, Monaten und Tagen. |
| `.getYears()` | Davon nur die vollen Jahre, also das Alter. |
| `java.time.` | Das Paket, in dem diese Klassen liegen. Mit `import java.time.*;` oben in der Datei kann man es weglassen. |

(Im Projekt sind `LocalDate` und `Period` schon importiert.)

## Achtung bei Überweisungen!
Eine Überweisung besteht aus zwei Buchungen: abbuchen und gutschreiben. Wenn du zuerst abbuchst und **danach** merkst, dass das Zielkonto gar nicht existiert, ist das Geld weg! Darum: **erst alles prüfen, dann buchen.** In echten Systemen löst man das mit **Datenbank-Transaktionen** (alles oder nichts) – ein gutes Stichwort fürs Interview.

class Bank {
    private final String name;
    private final Map<String, Konto> konten = new LinkedHashMap<>();
    private int naechsteNummer = 1;

    Bank(String name) {
        this.name = name;
    }

    Konto kontoEroeffnen(Kunde kunde) {
        if (kunde.alter() < 18) {
            throw new IllegalArgumentException("Kunde muss mindestens 18 Jahre alt sein");
        }
        String nummer = String.format("DE-%04d", naechsteNummer++);
        Konto konto = new Konto(nummer, kunde);
        konten.put(nummer, konto);
        System.out.println("Neues Konto " + nummer + " für " + kunde.name());
        return konto;
    }

    Konto finde(String kontonummer) {
        Konto konto = konten.get(kontonummer);
        if (konto == null) {
            throw new IllegalArgumentException("Konto nicht gefunden: " + kontonummer);
        }
        return konto;
    }

    void ueberweisen(String von, String nach, double betrag) {
        Konto quelle = finde(von);   // erst beide prüfen ...
        Konto ziel = finde(nach);
        quelle.auszahlen(betrag);    // ... dann buchen
        ziel.einzahlen(betrag);
    }

    void uebersicht() {
        System.out.println("=== " + name + " ===");
        double summe = 0;
        for (Konto k : konten.values()) {
            System.out.println(k);
            summe += k.getKontostand();
        }
        System.out.println("Summe aller Einlagen: " + Konto.euro(summe));
    }
}

--- erklaerung
Jede Bank zeigt, **welche Buchungen** es gab. Dafür speichert jedes Konto eine Liste von Buchungen (Transaktionen).

## Eine Buchung als record
```java
record Transaktion(String text, double betrag) {}   // betrag: + Eingang, - Ausgang
```
Eine Liste davon im Konto und einen Eintrag hinzufügen:
```java
private final List<Transaktion> verlauf = new ArrayList<>();
verlauf.add(new Transaktion("Einzahlung", 100));
```

## Überladene Methoden
Damit jede Buchung einen sinnvollen Text bekommt, gibt es zwei Versionen von `einzahlen` (**Overloading**). Die kurze ruft die lange mit einem Standardtext auf – so funktioniert alter Code weiter:
```java
void einzahlen(double betrag) {
    einzahlen(betrag, "Einzahlung");
}
```

## Summen mit Streams
```run
List<Double> betraege = List.of(100.0, -30.0, 50.0, -20.0);
double rein = betraege.stream().filter(b -> b > 0).mapToDouble(b -> b).sum();
double raus = betraege.stream().filter(b -> b < 0).mapToDouble(b -> -b).sum();
System.out.println(rein + " rein, " + raus + " raus");
```

| Baustein | Was er bedeutet |
|---|---|
| `betraege.stream()` | Die Beträge nacheinander durch eine Kette schicken. |
| `.filter(b -> b > 0)` | Nur positive Beträge (Eingänge) durchlassen. |
| `.mapToDouble(b -> b)` | In einen Zahlen-Stream umwandeln, der rechnen kann. Bei den Ausgängen macht `-b` die Beträge positiv. |
| `.sum()` | Alles zusammenzählen. |

class Konto {
    private final String kontonummer;
    private final Kunde inhaber;
    private double kontostand;
    private final List<Transaktion> verlauf = new ArrayList<>();

    Konto(String kontonummer, Kunde inhaber) {
        this.kontonummer = kontonummer;
        this.inhaber = inhaber;
    }

    void einzahlen(double betrag) {
        einzahlen(betrag, "Einzahlung");
    }

    void einzahlen(double betrag, String text) {
        if (betrag <= 0) throw new IllegalArgumentException("Betrag muss positiv sein");
        kontostand += betrag;
        verlauf.add(new Transaktion(text, betrag));
    }

    void auszahlen(double betrag) {
        auszahlen(betrag, "Auszahlung");
    }

    void auszahlen(double betrag, String text) {
        if (betrag <= 0) throw new IllegalArgumentException("Betrag muss positiv sein");
        if (betrag > kontostand) throw new IllegalStateException("Nicht genug Guthaben");
        kontostand -= betrag;
        verlauf.add(new Transaktion(text, -betrag));
    }

    void kontoauszug() {
        System.out.println("--- Kontoauszug " + kontonummer + " (" + inhaber.name() + ") ---");
        for (Transaktion t : verlauf) {
            System.out.println(String.format("%12s  %s", euro(t.betrag()), t.text()));
        }
        double eingaenge = verlauf.stream()
                .filter(t -> t.betrag() > 0)
                .mapToDouble(Transaktion::betrag)
                .sum();
        double ausgaenge = verlauf.stream()
                .filter(t -> t.betrag() < 0)
                .mapToDouble(t -> -t.betrag())
                .sum();
        System.out.println("Eingänge: " + euro(eingaenge) + " | Ausgänge: " + euro(ausgaenge));
        System.out.println("Kontostand: " + euro(kontostand));
    }

    String getKontonummer() { return kontonummer; }
    Kunde getInhaber() { return inhaber; }
    double getKontostand() { return kontostand; }

    static String euro(double betrag) {
        return String.format("%,.2f €", betrag);
    }

    @Override
    public String toString() {
        return "Konto " + kontonummer + " | " + inhaber.name() + " | " + euro(kontostand);
    }
}
