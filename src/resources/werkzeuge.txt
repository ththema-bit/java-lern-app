## Ohne IDE kompilieren
Mit dem Knopf **Als .java speichern** nimmst du deinen Code aus der App mit. Danach geht es im Terminal so weiter:
```java
javac Main.java     // erzeugt Main.class (Bytecode)
java Main           // startet das Programm
```

## IDE
**IntelliJ IDEA** ist die verbreitetste Java-IDE. Sie bietet Autovervollständigung, Debugger und Refactoring. Die kostenlose Community Edition reicht für den Einstieg.

## Maven
Maven lädt Bibliotheken und baut dein Projekt. Die Konfiguration steht in `pom.xml`.
| Befehl | Was passiert |
|---|---|
| `mvn test` | Tests ausführen |
| `mvn package` | JAR-Datei bauen |
| `mvn clean install` | Neu bauen und lokal installieren |

## Git
| Befehl | Was passiert |
|---|---|
| `git status` | Zeigt geänderte Dateien |
| `git add .` | Merkt Änderungen für den Commit vor |
| `git commit -m "Text"` | Speichert einen Stand |
| `git pull` / `git push` | Holt Änderungen / lädt sie hoch |
| `git switch -c name` | Erstellt einen neuen Branch |

Typischer Ablauf: Branch erstellen, Änderungen committen, pushen, Pull Request öffnen, Code-Review.

Viele Java-Stellen arbeiten mit Datenbanken und Web-APIs. Dieser Überblick gibt dir die Begriffe. Prüfe in der Stellenanzeige, was davon gefragt ist.

## SQL
```java
SELECT name, gehalt FROM mitarbeiter WHERE gehalt > 4000 ORDER BY gehalt DESC;
INSERT INTO mitarbeiter (name, gehalt) VALUES ('Anna', 5000);
UPDATE mitarbeiter SET gehalt = 5500 WHERE id = 1;
DELETE FROM mitarbeiter WHERE id = 1;

SELECT m.name, a.titel
FROM mitarbeiter m
JOIN abteilung a ON m.abteilung_id = a.id;
```
- **Primary Key:** eindeutige ID einer Zeile
- **Foreign Key:** Verweis auf eine Zeile in einer anderen Tabelle
- **JOIN:** Verbindet Tabellen über solche Schlüssel
- **Index:** Macht Suchen schneller, kostet aber Speicher und Schreibzeit

## REST & HTTP
| Methode | Bedeutung | Beispiel |
|---|---|---|
| `GET` | lesen | `GET /konten/1` |
| `POST` | anlegen | `POST /konten` |
| `PUT` | ersetzen | `PUT /konten/1` |
| `DELETE` | löschen | `DELETE /konten/1` |

Wichtige Statuscodes: **200** OK, **201** erstellt, **400** ungültige Anfrage, **404** nicht gefunden, **500** Serverfehler.

## Spring Boot
```java
@RestController
public class KontoController {
    private final KontoService service;

    public KontoController(KontoService service) {   // Dependency Injection
        this.service = service;
    }

    @GetMapping("/konten/{id}")
    public Konto finde(@PathVariable long id) {
        return service.finde(id);
    }
}
```
Die typischen Schichten heißen **Controller**, **Service** und **Repository**. Spring erzeugt die Objekte und reicht sie an die Konstruktoren weiter. Das nennt man **Dependency Injection**.
