import java.util.Arrays;

public class Main {
    static void umdrehen(int[] a) {
        int links = 0;
        int rechts = a.length - 1;
        while (links < rechts) {
            int temp = a[links];
            a[links] = a[rechts];
            a[rechts] = temp;
            links++;
            rechts--;
        }

public class Main {
    static int zweitgroesste(int[] a) {
        int groesste = Integer.MIN_VALUE;
        int zweite = Integer.MIN_VALUE;

            if (z > groesste) {
                zweite = groesste;
                groesste = z;

                zweite = z;
            }
        }

**Two Sum** gehört zu den bekanntesten Interview-Aufgaben: Finde zwei Zahlen, die zusammen einen Zielwert ergeben.

| Baustein | Was er bedeutet |
|---|---|

--- erklaerung
Eine klassische Aufgabe für einen **Stack**: Öffnende Klammern legst du ab. Bei einer schließenden Klammer muss oben die passende öffnende liegen. Am Ende muss der Stapel leer sein.
--- aufgabe

```java
false

true
```
--- tipps
Nutze `Deque<Character> stapel = new ArrayDeque<>();`.
Bei `(`, `[` oder `{` rufst du `push(c)` auf.
Bei einer schließenden Klammer: Ist der Stapel leer oder passt `pop()` nicht, gib `false` zurück. Am Ende gib `stapel.isEmpty()` zurück.
--- notizen
Zeichne den Stapel für `(a[b])` Schritt für Schritt auf Papier.
--- code
import java.util.*;

public class Main {
    static boolean istGueltig(String text) {
        return false; // TODO
    }
//@@
}
--- loesung
import java.util.*;

public class Main {
    static boolean istGueltig(String text) {
        Deque<Character> stapel = new ArrayDeque<>();
        for (char c : text.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                stapel.push(c);
            } else if (c == ')' || c == ']' || c == '}') {
                if (stapel.isEmpty()) return false;
                char offen = stapel.pop();
                boolean passt = (c == ')' && offen == '(')
                        || (c == ']' && offen == '[')
                        || (c == '}' && offen == '{');
                if (!passt) return false;
            }
        }
        return stapel.isEmpty();
    }
//@@
}

        System.out.println(istGueltig(""));
    }

id: w_binaer
kapitel: 8 · Übungs-Workout
titel: Binäre Suche
--- erklaerung
Die **binäre Suche** funktioniert nur bei **sortierten** Daten. Du schaust in die Mitte und verwirfst dann die Hälfte, in der der Wert nicht liegen kann. Das ergibt **O(log n)**: Bei einer Million Elementen reichen rund 20 Vergleiche.
--- aufgabe
Implementiere die binäre Suche mit einer Schleife. Gib den Index zurück oder `-1`, wenn der Wert fehlt.

```java
3
0
-1
```
--- tipps
Starte mit `links = 0` und `rechts = a.length - 1`.
Die Schleife läuft mit `while (links <= rechts)`, die Mitte ist `(links + rechts) / 2`.
Ist `a[mitte] < ziel`, gilt `links = mitte + 1`, sonst `rechts = mitte - 1`.
--- notizen
Schreib die binäre Suche aus dem Kopf auf und erkläre, warum sie O(log n) ist.
--- code
public class Main {
    static int suche(int[] a, int ziel) {
        return -1; // TODO
    }
//@@
}
--- loesung
public class Main {
    static int suche(int[] a, int ziel) {
        int links = 0;
        int rechts = a.length - 1;
        while (links <= rechts) {
            int mitte = (links + rechts) / 2;
            if (a[mitte] == ziel) {
                return mitte;
            } else if (a[mitte] < ziel) {
                links = mitte + 1;
            } else {
                rechts = mitte - 1;
            }
        }
        return -1;
    }
//@@
}
--- gemeinsam

        System.out.println(suche(sortiert, 4));

id: w_haeufigster
kapitel: 8 · Übungs-Workout
titel: Häufigster Buchstabe
--- erklaerung
Zählen mit einer Map ist eines der nützlichsten Muster überhaupt. `merge` macht es besonders kurz:

```run
Map<Character, Integer> zaehler = new HashMap<>();
zaehler.merge('a', 1, Integer::sum);
zaehler.merge('a', 1, Integer::sum);
System.out.println(zaehler);   // {a=2}
```
| Baustein | Was er bedeutet |
|---|---|
| `Map<Character, Integer>` | Zeichen → Anzahl. `Character` ist die Objekt-Version von `char`. |
| `zaehler.merge(` | „Füge einen Wert ein oder verrechne ihn mit dem vorhandenen.“ |
| `'a',` | Der Schlüssel. |
| `1,` | Der Wert, falls der Schlüssel noch fehlt. |
| `Integer::sum)` | Was passiert, wenn er schon da ist: alter Wert + 1. Kurzform von `(alt, neu) -> alt + neu`. |

Ohne `merge` sähe das so aus: `zaehler.put(c, zaehler.getOrDefault(c, 0) + 1);`

--- aufgabe
Finde den Buchstaben, der am häufigsten vorkommt.

```java
l
a
b
```
--- tipps
Zähle jeden Buchstaben in einer `Map<Character, Integer>`.
Geh danach durch `entrySet()`.
Merke dir den Eintrag mit dem höchsten Wert.
--- notizen
Schreib das Zähl-Muster mit `getOrDefault` und mit `merge` von Hand auf.
--- code
import java.util.*;

public class Main {
    static char haeufigster(String text) {
        return '?'; // TODO
    }
//@@
}
--- loesung
import java.util.*;

public class Main {
    static char haeufigster(String text) {
        Map<Character, Integer> zaehler = new HashMap<>();
        for (char c : text.toCharArray()) {
            zaehler.merge(c, 1, Integer::sum);
        }
        char bester = '?';
        int max = 0;
        for (Map.Entry<Character, Integer> e : zaehler.entrySet()) {
            if (e.getValue() > max) {
                max = e.getValue();
                bester = e.getKey();
            }
        }
        return bester;
    }
//@@
}

--- erklaerung

--- tipps
Das Ergebnis ist ein Array der Länge `a.length + b.length`.
Solange beide Arrays noch Elemente haben, nimmst du das kleinere.
Kopiere danach den Rest des übrigen Arrays.
--- notizen
Spiele das Zusammenführen von `[1, 3]` und `[2, 4]` auf Papier durch.
--- code

public class Main {
    static int[] zusammenfuehren(int[] a, int[] b) {
        return new int[0]; // TODO
    }
//@@
}
--- loesung
import java.util.Arrays;

public class Main {
    static int[] zusammenfuehren(int[] a, int[] b) {
        int[] ergebnis = new int[a.length + b.length];
        int i = 0, j = 0, k = 0;
        while (i < a.length && j < b.length) {
            if (a[i] <= b[j]) {
                ergebnis[k++] = a[i++];
            } else {
                ergebnis[k++] = b[j++];
            }
        }

titel: Mitarbeiter auswerten mit Streams
--- erklaerung
Daten filtern, gruppieren und zusammenfassen kommt im Java-Alltag ständig vor. `Collectors.groupingBy` gruppiert Elemente, und ein zweiter Collector rechnet pro Gruppe weiter.

```java
Map<String, Long> proAbteilung = liste.stream()
        .collect(Collectors.groupingBy(Mitarbeiter::abteilung, TreeMap::new, Collectors.counting()));
```
| Baustein | Was er bedeutet |
|---|---|
| `Collectors.groupingBy(` | Sortiert die Elemente in Gruppen. Das Ergebnis ist eine `Map`. |
| `Mitarbeiter::abteilung,` | **Wonach** gruppiert wird: Die Abteilung wird der Schlüssel. |
| `TreeMap::new,` | **Welche** Map entstehen soll. Eine `TreeMap` hält die Schlüssel sortiert. |
| `Collectors.counting())` | **Was** pro Gruppe ausgerechnet wird: die Anzahl. Deshalb ist der Wert ein `Long`. |
| `.average()` | Durchschnitt eines Zahlen-Streams. Das Ergebnis ist optional, weil die Liste leer sein könnte. |
| `.orElse(0)` | Ersatzwert, falls es keinen Durchschnitt gibt. |

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Mitarbeiter> liste = List.of(
                new Mitarbeiter("Lisa", "IT", 6000),
                new Mitarbeiter("Jan", "IT", 4000),
                new Mitarbeiter("Eva", "HR", 3500));

        Map<String, Long> proAbteilung = liste.stream()
                .collect(Collectors.groupingBy(Mitarbeiter::abteilung, TreeMap::new, Collectors.counting()));
        System.out.println(proAbteilung);

        String bester = liste.stream()
                .max(Comparator.comparingInt(Mitarbeiter::gehalt))
                .map(Mitarbeiter::name)
                .orElse("-");
        System.out.println(bester);

        double schnitt = liste.stream()
                .filter(m -> m.abteilung().equals("IT"))
                .mapToInt(Mitarbeiter::gehalt)
                .average()
                .orElse(0);
        System.out.println(schnitt);
    }
}
